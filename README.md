# PMX ラティス補助

PMX Editor上で、衣装などの選択した頂点を格子で変形するDLLプラグインです。公開版のバージョンは **1.0.0** です。

材質または選択頂点から格子を作り、全体の位置合わせ、段ごとの幅・奥行き、制御点を調整できます。身体を表示しながら衣装だけを編集し、複数の対象を順に調整して最後にまとめて反映できます。

## インストール

1. 配布ZIPを展開します。
2. PMX Editorを終了します。
3. `PmxLattice` フォルダーをPMX Editorの `_plugin/User/` にコピーします。
4. PMX Editorを起動し、プラグイン一覧から「PMX ラティス補助」を開きます。

以前の版がある場合は、旧DLLを削除してから配置してください。別フォルダーに旧版と新版のDLLを同時に残さないでください。

PMX Editor 0.2.7.3付属のSDKを使用してビルドしています。ほかのバージョンおよび32bit環境での動作は未確認です。PEPlugin.dllやSlimDX.dllは配布物に含めず、PMX Editorに付属するものを使用します。

## 使い方

1. 編集するモデルをPMX Editorで開き、プラグインを起動します。
2. 「表示材質」で身体と衣装など、確認に必要な材質を表示します。
3. 「変形対象・操作」で衣装の材質を選び、「選んだ材質で格子を作成」を押します。PMXViewの選択頂点から作成することもできます。
4. 「格子全体を移動」で位置を合わせます。段ごとの幅・奥行き、段の移動、制御点の個別移動で形を調整します。
5. 別の対象を編集するときは「保持して対象変更」で現在の修正を残して切り替えます。
6. 「本体へ反映して閉じる」で修正をまとめて反映し、PMX Editor側でモデルを保存します。

表示する材質と変形対象は独立しています。身体を表示しても、対象に選ばなければ身体は変形しません。

## 操作

| 操作 | 内容 |
| --- | --- |
| 左ドラッグ | 選択したモードで格子・段・制御点を移動 |
| 右ドラッグ | プレビュー表示を移動 |
| ホイール | プレビューを拡大・縮小 |
| Ctrl+Z | プラグイン内の編集を戻す |
| Ctrl+Y / Ctrl+Shift+Z | プラグイン内の編集をやり直す |
| 形状調整をリセット（位置は保持） | 全体移動による位置合わせを残して形状調整を戻す |

ショートカットはプラグインのウィンドウ内で有効です。プラグイン内の編集は最終反映までPMX Editor本体に書き込みません。本体へ反映した後のUndoはこのプラグイン内のUndoとは別です。

## 対応範囲

- 変更するのは対象頂点の位置です。骨、ウェイト、材質、UV、面構成、既存モーフ、物理設定を追従させる機能はありません。
- モデルの法線やSDEF基準点も更新しません。形状変更後のモーフや物理の動作は別途確認してください。
- プレビューは主テクスチャと材質色を表示します。スフィア、トゥーン、影などのMMD表示は再現しません。TGAテクスチャは未対応です。
- 自動位置合わせ、自動フィッティング、対称編集、格子の保存には対応していません。
- プラグインを開いたまま本体で別の編集やモデル切替を行うと、上書きを防ぐため反映を拒否します。その場合はプラグインを閉じて開き直してください。

## ソースのビルド

Windowsの.NET Framework C#コンパイラーと、インストール済みPMX EditorのSDKを使用します。

```powershell
.\build.ps1 -EditorPath 'C:\path\to\PmxEditor'
.\test.ps1 -EditorPath 'C:\path\to\PmxEditor'
```

DLLは `dist/PmxLattice.dll` に生成されます。モデルを使う追加検査は `test.ps1` の `-Models` に手元のPMXファイルを渡します。モデル・テクスチャ・SDKはこのリポジトリに含みません。
